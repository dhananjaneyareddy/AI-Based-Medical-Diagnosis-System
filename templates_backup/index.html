ABOUT OUR PROJECT

AI-Based Medical Diagnosis System

Our AI-Based Medical Diagnosis System is a machine learning web application designed to predict a possible disease based on the symptoms selected by the user.

The system uses medical datasets and a trained machine learning model to analyze symptoms and generate a prediction. It also provides useful information such as precautions, medicines, prediction history, and statistics.
